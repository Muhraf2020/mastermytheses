Reading pathways

Most of these books stand alone, but some are written to be read in sequence — the clinical series in particular, where each workbook assumes the one before it. These are the orders that work.

  3. 3. Literature Review Simplified: A Practical Guide for Beginners — Second Edition
  4. 4. The Qualitative Coding Workbook
  5. 5. The Statistical Test Selection Workbook
  6. 6. The Academic Writing and Scholarly Style Workbook
